# 自动化项目实施总计划看板

体育鞋服客户 ASRS 自动化仓库项目 · 施工实施总计划可视化看板

## 在线访问

打开以下链接即可查看最新看板（无需安装任何软件，手机/电脑浏览器均可访问）：

**https://zhaohuahua-sys.github.io/construction-board/**

## 数据同步机制

看板数据来自本仓库 `data/Phase II 施工总览.xlsx`，打开网页时自动读取仓库中的最新 Excel 并渲染。

| 场景 | 数据来源 |
|------|----------|
| 在线访问（GitHub Pages） | 仓库 `data/` 目录中的最新 Excel ✅ 自动同步 |
| 本地双击打开 HTML | 内置快照数据（离线兜底） |

## 如何更新数据

每次更新 Excel 表格内容后，只需把最新表格推送到本仓库：

1. 将更新后的 Excel 保存为 `Phase II 施工总览.xlsx`（或保留原文件名）
2. 覆盖上传到本仓库 `data/` 目录
3. 网页自动展示最新数据（浏览器刷新即可，GitHub Pages 约 1 分钟内生效）

> 本地也可直接运行「一键同步」脚本自动完成复制与推送。

## 看板功能

- 甘特图时间轴（缩放 / 平移 / 回到今天 / 适应窗口）
- 总览视图：运营高峰风险分析、未来 7/14 天施工冲突预警
- 分组筛选、搜索、悬浮详情提示
- 优先级规则横幅（运营计划 > 施工项 > 提前改造项）
- 支持手动选择本地 Excel 重新渲染
